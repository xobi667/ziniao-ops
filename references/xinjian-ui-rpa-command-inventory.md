## How To Use

- Use commands[].commands.exact_query to select a remembered action by exact ID.
- Use commands[].commands.dry_run before execution.
- Use execute_safe only for safe non-write actions.
- Use read_table_column for visible table values on a debuggable CDP page; it does not click.
- Use row_context only after row index/text is known; it never defaults to the first row.
- Use confirmed_write or confirmed_export only after explicit confirmation.
